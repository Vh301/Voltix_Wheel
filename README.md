# Voltix Wheel

Mobile game landing and technical rotor prototype for the Voltix Reactor / flywheel generator concept.

## URLs

- **Production (landing):** https://voltix-wheel.vercel.app/
- **Rotor prototype:** https://voltix-wheel.vercel.app/prototype

## Stack

Next.js App Router · React · TypeScript · Tailwind CSS · Vercel

## Documentation

See [`doc/README.md`](doc/README.md) for concept, copy, strategy, and audit reports.

## Project layout

- `app/` — routes (`/` landing, `/prototype` rotor test)
- `components/` — UI (landing + prototype)
- `lib/prototype/` — rotor physics and swipe simulation
- `public/images/` — production assets used by the site
- `doc/` — project documentation
