# Voltix Wheel — Product Placement & Native Brand Integration Strategy

## 1. Главная идея / Core idea

**Voltix Wheel** не показывает пользователю скучные баннеры поверх игры.

Реклама встраивается в мир игры как естественная часть реакторной станции — **sponsor moments inside the Voltix Reactor world**.

Ключевой принцип (EN):

```txt
Not banners. Sponsor moments built into the Voltix Reactor.
```

Русский смысл:

```txt
Не баннеры. А брендовые моменты, встроенные в игровой мир Voltix Reactor.
```

### Как это выглядит в мире игры

Бренд появляется не как «рекламный блок», а как часть оборудования и атмосферы **Voltix Reactor**:

- бутылка напитка в **Cooling Station**;
- мини-холодильник как брендированное оборудование;
- монитор управления как техника партнёра;
- постер на стене реакторной мастерской;
- шильдик производителя на **VW Token Printer**;
- брендированный буст;
- **sponsor challenge**;
- **sponsored Daily Reward Pool**.

### Главная формула

```txt
Brand → Game object → Player action → Reward / emotion
```

### Чего мы избегаем

```txt
Brand → Banner → Forced attention
```

---

## 2. Почему это подходит Voltix Wheel / Why this fits Voltix Wheel

Voltix Wheel особенно хорошо подходит под нативный product placement по нескольким причинам:

1. **Физически понятное пространство** — игра строится вокруг reactor room / workshop, а не абстрактного UI.
2. **Много естественных объектов** — wheel, printer, fridge, monitor, pipes, batteries, panels, cables.
3. **Постоянный visual focus на machinery** — игрок регулярно смотрит на оборудование, значит бренд может быть частью среды, а не «вставкой сверху».
4. **Daily Reward Pool** — естественная точка для sponsor-powered rewards.
5. **Energy mechanics** — позволяют делать **optional sponsor boosts** без навязчивости.
6. **Ежедневные задания** — основа для sponsor challenges.
7. **Визуальный стиль blue/gold sci-fi** — премиальные бренды выглядят органично, если интегрированы аккуратно.

Игровая цепочка, вокруг которой строится monetization logic:

```txt
Voltix → Reactor Wheel → Energy → Voltix Reactor → VW Token Printer → Rewards
```

## 4. Уровни product placement для Voltix Wheel

### Level 1 — Native Props

Самый простой и безопасный уровень.

Бренд появляется как физический объект внутри мира.

| Формат спонсора | Игровой объект | Пример |
|---|---|---|
| Drink brand | bottle/can in cooling station | energy drink, cola, water |
| Appliance brand | mini-fridge / cooling unit | premium fridge badge |
| Tech brand | monitor / reactor display | control screen |
| Auto brand | wall poster / speed poster | garage-style poster |
| Hardware brand | badge on VW Token Printer | manufacturer plate |
| Battery brand | battery module | power cell branding |

**Правило:**

```txt
Small, visible, natural, non-intrusive.
```

**Русский смысл:** маленький, заметный, естественный, ненавязчивый.

---

### Level 2 — Rewarded Sponsor Moments

Бренд связан с **добровольным** действием игрока.

Примеры:

- claim sponsor boost;
- open sponsor chest;
- complete sponsor task;
- activate sponsor energy refill;
- use sponsor cooling station;
- join sponsor daily challenge.

**Важно:**

- игрок сам выбирает участие;
- нет принудительного просмотра;
- награда должна быть игровой: energy, boost, chest, multiplier, cosmetic, event ticket;
- формулировка должна быть мягкой.

**Лучшее название (EN):**

```txt
Optional sponsor boosts
```

**Не использовать слишком грубое:**

```txt
Rewarded ads
```

**Русская player-facing формулировка:**

```txt
Опциональный спонсорский буст
```

---

### Level 3 — Sponsored Game Systems

Самый ценный уровень для крупных партнёров.

Бренд становится частью игровой системы или события.

#### Sponsored Daily Reward Pool

Бренд поддерживает дневной пул наград.

Игровая формулировка (EN):

```txt
Today's Daily Reward Pool is charged by <Sponsor>.
```

Русская версия:

```txt
Сегодняшний Daily Reward Pool заряжен партнёром <Sponsor>.
```

#### Sponsor Reactor Upgrade

Бренд связан с улучшением реактора.

Примеры:

```txt
Cooling Station Upgrade
Speed Coil Upgrade
Energy Battery Upgrade
Printer Efficiency Upgrade
```

#### Sponsor Challenge Week

Бренд запускает неделю заданий.

Пример (EN):

```txt
Complete energy tasks and charge the reactor together.
```

Русская версия:

```txt
Выполняй энергетические задания и заряжай реактор вместе с партнёром.
```

#### Sponsor Equipment Skin

Бренд получает аккуратный скин оборудования:

- fridge skin;
- monitor skin;
- token printer badge;
- battery module skin;
- reactor panel skin.

## 6. Правила: что можно и чего нельзя / Rules

### Allowed — Разрешено

- small integrated brand props;
- sponsor equipment;
- optional sponsor boosts;
- sponsor challenges;
- sponsored reward pool;
- branded cosmetic skins;
- brand posters inside environment;
- brand screens inside machinery.

**Русский смысл:** только встроенные, добровольные и игровые форматы присутствия бренда.

### Not allowed / avoid — Запрещено / избегать

- banner ads over the game;
- popups blocking gameplay;
- forced ad watching as core loop;
- huge logos covering the screen;
- misleading «earn money» promises;
- sponsor overload;
- brands that conflict with premium/family-safe positioning;
- adult/gambling/nicotine/unsafe categories unless separately approved.

**Русский смысл:** никаких баннеров, попапов, принудительного просмотра и перегруза брендами.

### Tone rule — Правило тона

Player-facing text should feel like:

```txt
A sponsor moment inside the game world.
```

Not like:

```txt
An advertising unit.
```

**Русская версия:**

```txt
Спонсорский момент внутри игрового мира — да.
Рекламный блок — нет.
```

## 8. Модель монетизации / Monetization model

### Package A — Native Prop Placement

Small sponsor object in game environment.

**Для кого:** drinks, appliances, hardware, electronics, automotive posters.

**Deliverables:**

- logo/badge;
- optional link or sponsor info;

## 12. Image Generation Prompt — Product Placement Concept

Ниже — готовый промпт для генерации нового визуального концепта с нативными sponsor placements.

### Prompt

```txt
Create a premium vertical 9:16 mobile game home screen concept for “Voltix Wheel” focused on native product placement inside the Voltix Reactor world.

Goal:
Show how sponsor placements can be naturally integrated into the game environment without looking like banner ads. The image should feel like a real premium mobile game screen, not an advertising mockup.

Game identity:
Voltix Wheel is a mobile energy game where the character Voltix runs inside a reactor generator wheel, charges the Voltix Reactor, and activates the VW Token Printer that produces shiny VW rewards.

Core visual chain:
Voltix → Reactor Wheel → Energy → Voltix Reactor → VW Token Printer → Rewards

Scene:
A futuristic dark blue and electric-gold reactor workshop called “Voltix Reactor”. Premium 3D cartoon game-art style, app-store-quality, glossy UI, polished sci-fi machinery, blue/gold electric glow, readable mobile UI.

Main elements:
- Voltix running dynamically inside a premium blue-and-gold reactor wheel
- glowing energy cables flowing from the wheel into the Voltix Reactor
- visible VW Token Printer printing shiny gold “VW” coins from a slot or conveyor
- Energy Power meter
- Daily Reward Pool panel
- large “SPIN THE WHEEL” button
- clean top bar with level, VW balance, energy balance, and profile avatar
- bottom navigation with Home, Mine, Boosts, Tasks, Wallet

Native sponsor placement strategy:
Integrate sponsor spots as physical objects inside the reactor workshop. They must feel like part of the environment, not ads.

Sponsor placements to show:
1. Cooling Station Sponsor
   - a mini cooling unit / mini fridge near the wheel
   - a drink bottle or can inside the fridge
   - small tasteful badge: “Cola Sponsor” or “Drink Partner”

2. Premium Appliance Partner

   - it should feel like a real premium equipment placement

3. Tech Display Partner
   - a reactor control monitor integrated into the machinery
   - small label: “Tech Display Partner”

4. Performance Partner

5. VW Token Printer Sponsor Badge

6. Daily Pool Sponsor

   - a small task/boost card in the UI:

   - should look like a game reward card, not an ad panel

Important:
- Do not use real brand logos in this concept.
- Use neutral placeholder sponsor labels only.
- No intrusive banners.
- No popups.
- No large ad rectangles.
- No clutter.
- Sponsor elements must remain secondary to the game.
- The game must still be the hero.
- The VW Token Printer must remain highly visible.
- The main emotional focus is: run the wheel, charge the reactor, print VW rewards.

Style:
premium 3D cartoon, futuristic mobile game UI, polished game-art quality, blue and gold electric palette, clean and readable, playful but not childish, professional product concept, high-end landing-page hero visual.
```
